# Publication du site

Seul le dossier `site/` est publié. Tout le reste du dépôt (prototypes, notes) ne part jamais en ligne.

Réglages Cloudflare Pages (projet relié à GitHub) :
- Branche de production : `main`
- Commande de build : aucune
- Dossier de sortie : `site`
- Aperçus de branches : désactivés

Règle : chaque fusion dans `main` publie le site. On travaille sur une branche, puis on fusionne par une PR.
